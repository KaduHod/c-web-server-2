# Servidor Web Modular em C

Um servidor web modular escrito em C com estrutura de dados customizadas e sistema de requisição/resposta.

## 📋 Pré-requisitos

- GCC (GNU Compiler Collection)
- Make
- Docker (opcional, para execução em container)
- Docker Compose (opcional)

## 🚀 Como executar

### Compilação manual

```bash
make build
```

### Execução

```bash
make run
```

### Execução com Docker

```bash
docker-compose up --build
```
## 🔧 Funcionalidades Principais

- **Servidor HTTP** básico implementado em C
- **Sistema modular** de requisição/resposta
- **Estruturas de dados** customizadas:
  - Dicionários
  - Listas encadeadas
  - Filas
  - Árvores binárias
- **Utilitários** para manipulação de datas
- **Configuração Docker** para execução em container
